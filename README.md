Веприков Егор Русланович, группа 221141, вариант 7, лабораторная №2

Пять задач варианта: подсчёт гласных; минимальный элемент; факториал; частота слов в файле; игра «Угадай число».

## Запуск

Из этой папки:

```bash
python main.py
python -m pytest
```

`main.py` показывает факториалы, число гласных, минимум списка, частоты из `data/words.txt` и шаги автоподбора.

## Что лежит в модулях

`count_vowels` (`vowels.py`) идёт по строке и считает гласные.

`list_minimum` (`minimum.py`) ищет наименьший элемент обычным циклом. Пустой список — `ValueError`. Встроенный `min` здесь не вызывается: смысл задания как раз в цикле.

`factorial` (`factorial.py`) считает факториал последовательным умножением. Ноль даёт 1, отрицательное число — `ValueError`.

`word_counts` (`words.py`) читает UTF-8 файл и складывает словарь «слово → число вхождений».

`compare_guess` (`guess.py`) отвечает, куда двигаться относительно секрета. `autoplay` подбирает секрет двоичным поиском и заканчивает вердиктом `equal`.

## Правила разбора

Гласные: русские аеёиоуыэюя и латинские aeiouy, без учёта регистра, буква ё считается.

Слова — токены регулярного выражения `[0-9A-Za-zА-Яа-яЁё]+`, приведённые к нижнему регистру.
